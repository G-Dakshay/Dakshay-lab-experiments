Optical Fibre NA Scanner

The graph-paper screen is replaced by a small photodiode that slides across the light spot on a lead screw. An Arduino finds the two edges of the spot, reads the distance L from a ToF sensor, and sends D1, D2 and L to Python, which returns the numerical aperture with an uncertainty.

Overview

From light cone to NA

Marking the edge of a glowing spot by eye is the weakest step in this experiment. Two people will draw two different circles. The scanner replaces that judgement with a fixed rule: the edge is where the brightness falls to 5% of the peak, which is also the usual definition of NA for a fibre.

  1. Fibre emits a cone

    Light leaves the exit end and spreads at the acceptance half-angle θₐ, where NA = sin θₐ.

  2. Sensor reads the spot

    A photodiode behind a 1 mm pinhole sits on a carriage at distance L from the fibre end.

  3. Carriage sweeps

    A stepper moves it across the spot in 0.5 mm steps. The Arduino records the brightness at every stop.

  4. Edges found at 5%

    The two crossings of 5% of the peak, interpolated between steps, give the diameter D.

  5. Rotate and repeat

    Turning the scanner 90° gives the second diameter, so you get D1 and D2 as in Table 3.

  6. ToF reads L

    A VL53L1X measures L without a ruler. Python then applies NA = D / √(D² + 4L²).

Mechanics

The rig

Everything sits on the optical bench you already use. Only the screen is replaced.

Pinhole sets the resolution

A 1 mm pinhole over the photodiode with 0.5 mm steps places an edge to about 0.1 mm after interpolation.

Centre the sensor height

Set the carriage to the fibre's height with a ruler. A 2 mm miss on a 40 mm spot shortens D by only 0.2 mm, which is 0.5%.

Keep the spot on the screw

Choose L so D stays under about 130 mm. For a plastic fibre with NA 0.5 that means L up to about 11 cm.

Use 5 to 15 cm for L

The ToF sensor does not read reliably below about 4 cm.

Shade the sensor

A short black tube around the photodiode and a dark reading at both ends of every scan remove room light.

Laser safety

Never look into the fibre end or the beam. Use the low-power diode from the lab kit.

Firmware

What the Arduino does

Six states in a fixed order. Homing gives every scan the same zero, the 5% rule gives every edge the same definition, and the ToF reading gives every L without a ruler. The only manual steps are turning the scanner and pressing the button.

scanner.ino
#include <Wire.h>
#include <VL53L1X.h>            // Pololu VL53L1X library

const uint8_t STEP_PIN = 3, DIR_PIN = 4, EN_PIN = 5;
const uint8_t LIMIT = 6, BTN = 2, LED = 13, PD = A0;

const float STEPS_PER_MM = 400.0;   // 200 steps x 16 microsteps / 8 mm lead
const float STEP_MM      = 0.5;     // spacing between readings
const int   N            = 300;     // 300 x 0.5 mm = 150 mm of travel
const int   MARGIN       = 8;       // points at each end that must lie outside the spot
const float EDGE_FRAC    = 0.05;    // edge = 5% of the peak above the dark level
const float L_OFFSET_MM  = 28.0;    // ToF to sensor plane. Measure once with a ruler.
const long  STEPS_PER_READING = (long)(STEP_MM * STEPS_PER_MM);

VL53L1X tof;
uint16_t buf[N];

void moveSteps(long n, bool away, unsigned us) {
  digitalWrite(DIR_PIN, away ? HIGH : LOW);   // flip if your motor runs the other way
  for (long i = 0; i < n; i++) {
    digitalWrite(STEP_PIN, HIGH); delayMicroseconds(us);
    digitalWrite(STEP_PIN, LOW);  delayMicroseconds(us);
  }
}

uint16_t readLight() {                         // 32 averaged reads
  uint32_t s = 0;
  for (uint8_t i = 0; i < 32; i++) s += analogRead(PD);
  return s / 32;
}

float readL() {                                // distance in mm
  float s = 0;
  for (uint8_t i = 0; i < 20; i++) s += tof.read();
  return s / 20.0 + L_OFFSET_MM;
}

void homeCarriage() {
  digitalWrite(DIR_PIN, LOW);                  // toward the limit switch
  while (digitalRead(LIMIT) == HIGH) {
    digitalWrite(LED, (millis() / 100) % 2);
    moveSteps(1, false, 250);
  }
  moveSteps(5 * STEPS_PER_MM, true, 250);      // back off 5 mm: this is position 0
}

void scan() {
  digitalWrite(LED, HIGH);
  for (int i = 0; i < N; i++) {
    if (i > 0) { moveSteps(STEPS_PER_READING, true, 125); delay(20); }
    buf[i] = readLight();
  }
}

void returnToZero() { moveSteps((long)(N - 1) * STEPS_PER_READING, false, 100); }

bool findDiameter(float &D) {
  float dark = 0;                              // average of both ends, outside the spot
  for (int i = 0; i < MARGIN; i++) dark += buf[i] + buf[N - 1 - i];
  dark /= 2 * MARGIN;
  float peak = 0;
  for (int i = 1; i < N - 1; i++) {            // 3-point smoothing for the peak only
    float s = (buf[i - 1] + buf[i] + buf[i + 1]) / 3.0;
    if (s > peak) peak = s;
  }
  peak -= dark;
  if (peak < 50) return false;                 // no spot, or too dim
  float thr = dark + EDGE_FRAC * peak;
  int a = -1, b = -1;
  for (int i = 0; i < N; i++) if (buf[i] >= thr) { if (a < 0) a = i; b = i; }
  if (a < MARGIN || b > N - 1 - MARGIN) return false;   // spot runs off the travel
  float xl = (a - 1) + (thr - buf[a - 1]) / (float)(buf[a] - buf[a - 1]);
  float xr = b + (buf[b] - thr) / (float)(buf[b] - buf[b + 1]);
  D = (xr - xl) * STEP_MM;
  return true;
}

void sendProfile(uint8_t axis) {
  for (int i = 0; i < N; i++) {
    Serial.print("P,"); Serial.print(axis); Serial.print(',');
    Serial.print(i * STEP_MM, 1); Serial.print(','); Serial.println(buf[i]);
  }
}

void waitButton(unsigned blinkMs) {
  while (digitalRead(BTN) == HIGH) digitalWrite(LED, (millis() / blinkMs) % 2);
  delay(30);
  while (digitalRead(BTN) == LOW) {}
  digitalWrite(LED, LOW);
}

void setup() {
  Serial.begin(115200);
  pinMode(STEP_PIN, OUTPUT); pinMode(DIR_PIN, OUTPUT); pinMode(EN_PIN, OUTPUT);
  pinMode(LIMIT, INPUT_PULLUP); pinMode(BTN, INPUT_PULLUP); pinMode(LED, OUTPUT);
  digitalWrite(EN_PIN, LOW);                   // A4988 enable is active low
  Wire.begin();
  tof.setTimeout(500);
  if (!tof.init()) { while (true) { digitalWrite(LED, !digitalRead(LED)); delay(80); } }
  tof.setDistanceMode(VL53L1X::Short);
  tof.setMeasurementTimingBudget(50000);
  tof.startContinuous(50);
  Serial.println("# ready, press the button");
}

void loop() {
  waitButton(500);
  homeCarriage();                              // HOME
  float L = readL();                           // READ L

  scan(); returnToZero();                      // SCAN 1
  sendProfile(1);
  float D1 = 0, D2 = 0;
  bool ok1 = findDiameter(D1);

  Serial.println("# rotate the scanner 90 degrees, then press the button");
  waitButton(500);                             // ROTATE
  scan(); returnToZero();                      // SCAN 2
  sendProfile(2);
  bool ok2 = findDiameter(D2);

  if (!ok1 || !ok2) { Serial.println("E,spot too dim or wider than the travel"); return; }
  float D  = (D1 + D2) / 2.0;                  // REPORT
  float NA = D / sqrt(D * D + 4.0 * L * L);
  Serial.print("R,"); Serial.print(L, 1);  Serial.print(',');
  Serial.print(D1, 2); Serial.print(',');  Serial.print(D2, 2); Serial.print(',');
  Serial.print(D, 2);  Serial.print(',');  Serial.println(NA, 4);
}
Simulation

Run a simulated scan

This models the scanner, it is not recorded data. Pick a fibre and press the button. The carriage homes, reads L, scans along one direction, turns 90°, scans again and reports. The firmware's edge search runs on noisy counts, and the NA it returns is compared with the value you set. All noise levels and offsets are assumptions you can change.

Analysis

Capture and fit

The first script saves each run. The second prints Table 3 and fits D = m(L + L₀). The slope m equals 2 tan θₐ, so it gives NA without relying on any single L, and the intercept shows a constant error in L.

capture.py
import sys, csv, serial                 # pip install pyserial

ser = serial.Serial(sys.argv[1], 115200, timeout=5)    # e.g. COM3
n, prof = 0, []
print("Press the scanner button. Ctrl+C to stop.")
while True:
    line = ser.readline().decode(errors="ignore").strip()
    if line.startswith("#"):
        print(line)
    elif line.startswith("P,"):                         # raw profile point
        _, axis, x, counts = line.split(",")
        prof.append((n + 1, int(axis), float(x), int(counts)))
    elif line.startswith("R,"):                         # finished run
        n += 1
        with open("runs.csv", "a", newline="") as f:
            csv.writer(f).writerow(line.split(",")[1:]) # L, D1, D2, D, NA
        with open("profiles.csv", "a", newline="") as f:
            csv.writer(f).writerows(prof)
        print(f"run {n}: {line}")
        prof = []
    elif line.startswith("E,"):
        print(line)
        prof = []
fit.py
import sys
import numpy as np, pandas as pd
from scipy.stats import linregress

runs = pd.read_csv(sys.argv[1], names=["L", "D1", "D2", "D", "NA"])   # mm
runs["theta"] = np.degrees(np.arcsin(runs.NA))
print(runs.round(4).to_string(index=False))
print(f"\nmean NA = {runs.NA.mean():.4f} +/- {runs.NA.std(ddof=1):.4f}"
      f"  (n = {len(runs)})")

# D = m (L + L0): slope m = 2 tan(theta), intercept shows a constant error in L
fit = linregress(runs.L, runs.D)         # the +/- values need 5 or more distances
t = fit.slope / 2
na_fit = t / np.sqrt(1 + t * t)
d_na = 0.5 * (1 + t * t) ** -1.5 * fit.stderr
off = -fit.intercept / fit.slope
d_off = fit.intercept_stderr / fit.slope
print(f"fit NA   = {na_fit:.4f} +/- {d_na:.4f}")
print(f"theta_a  = {np.degrees(np.arcsin(na_fit)):.2f} degrees")
print(f"L offset = {off:.1f} +/- {d_off:.1f} mm  (positive means L reads too long)")

Before you quote numbers

  • Command a 100 mm move and check it with a ruler. Correct STEPS_PER_MM if it is off.
  • Measure the ToF offset once, then check the ToF against a ruler at three distances.
  • Keep the peak between about 100 and 900 counts. A larger pinhole or a smaller one, or a piece of tinted film, changes it. Saturation lowers the measured peak, so the 5% level sits too low and D reads too large.
  • Run each L at least three times and report the mean and standard deviation of NA.
  • For a meaningful ± from the fit, use five or more distances. With three, the line has one degree of freedom and the standard errors can be far too small.
  • State in the report that the edge is defined at 5% of the peak. An edge picked by eye can sit at a higher fraction and give a smaller D and NA.
  • profiles.csv keeps every raw scan, so the edges can be recomputed later at another threshold.
Spot profile, sensor noise, offsets and fibre values in the simulation are assumptions made for illustration. NA 0.22, 0.275 and 0.50 are typical catalogue values for these fibre types. Check your own fibre. The Arduino sketch is written for the Pololu VL53L1X library and an A4988 driver. It has not been run on real hardware, so check pin labels, motor direction and step counts before powering up.
