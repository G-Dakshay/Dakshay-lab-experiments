Damped Oscillation Logger

A spring, a mass and a beaker, read by a distance sensor instead of a stopwatch. An Arduino records the whole decay curve, and a short Python script turns it into the period, the damping constant and their uncertainties.

Overview

From swinging mass to numbers

You pull the mass down and let go. Every step after that runs without a hand on a button, which removes the reaction-time error of the stopwatch method.

  1. Mass oscillates

    The spring pulls it back and the liquid drags on it, so each swing is smaller than the last.

  2. Flag follows

    A matte white flag on a thin rod rides above the liquid and moves with the mass.

  3. Sensor ranges

    A VL53L1X times infrared pulses bouncing off the flag, 50 times a second, to the nearest millimetre.

  4. Arduino stamps

    Each reading gets a time from the Arduino clock, so timing never depends on a person.

  5. USB to laptop

    Lines of text such as 1240.0,127 arrive over serial and are saved as a CSV.

  6. Python fits

    A decaying cosine is fitted to the data. T and γ come out with uncertainties, and b = 2mγ follows.

Mechanics

The rig

Flag beside the spring

The sensor needs a clear line to the flag. Mounting the flag on a rod next to the spring keeps the beam out of the coils.

Matte white surface

Shiny or transparent surfaces return erratic distances. A sheet of plain white card gives clean readings.

Keep it in range

Hold the flag between 5 and 30 cm below the sensor. The model in this page uses a rest distance of 12 cm.

Keep the motion vertical

A loose guide ring or a stiff rod stops sideways swing, which would show up as a false signal.

Rigid sensor mount

Any wobble in the arm reads as oscillation, so clamp it firmly.

Firmware

What the Arduino does

Four states, always in the same order. The calibration removes any need to align the sensor exactly, and the trigger removes the need to press anything at the moment of release.

logger.ino
#include <Wire.h>
#include <VL53L1X.h>           // Pololu VL53L1X library

VL53L1X sensor;
const uint8_t BTN = 2, LED = 13;
const int TRIGGER_MM = 5;      // movement from rest that starts logging
const int SETTLED_MM = 6;      // stop when 1 s of readings spans less than this
const unsigned long MAX_MS = 60000UL;

enum State { CALIBRATE, ARMED, LOGGING, DONE };
State state = CALIBRATE;

float d0 = 0, sum = 0;
int nCal = 0;
uint16_t win[50];              // the last second of readings
uint8_t wi = 0, filled = 0;
unsigned long t0us, tStartMs;

void logSample(uint16_t d) {
  Serial.print((micros() - t0us) / 1000.0, 1);
  Serial.print(',');
  Serial.println(d);
  win[wi] = d; wi = (wi + 1) % 50;
  if (filled < 50) filled++;
}

void setup() {
  Serial.begin(115200);
  pinMode(BTN, INPUT_PULLUP);
  pinMode(LED, OUTPUT);
  Wire.begin();
  Wire.setClock(400000);
  sensor.setTimeout(500);
  if (!sensor.init()) {        // sensor not found: blink fast forever
    while (true) { digitalWrite(LED, !digitalRead(LED)); delay(80); }
  }
  sensor.setDistanceMode(VL53L1X::Short);
  sensor.setMeasurementTimingBudget(20000);  // 20 ms per measurement
  sensor.startContinuous(20);                // a reading every 20 ms = 50 Hz
}

void loop() {
  uint16_t d = sensor.read();  // waits for the next reading
  unsigned long ms = millis();

  switch (state) {
    case CALIBRATE:
      digitalWrite(LED, (ms / 100) % 2);
      sum += d;
      if (++nCal == 50) {      // 1 s of readings
        d0 = sum / nCal;
        Serial.print("# d0_mm="); Serial.println(d0, 1);
        state = ARMED;
      }
      break;

    case ARMED:
      digitalWrite(LED, (ms / 500) % 2);
      if (abs((int)d - (int)d0) > TRIGGER_MM) {
        Serial.println("t_ms,d_mm");
        t0us = micros(); tStartMs = ms; wi = 0; filled = 0;
        logSample(d);
        state = LOGGING;
      }
      break;

    case LOGGING: {
      digitalWrite(LED, HIGH);
      logSample(d);
      uint16_t lo = 65535, hi = 0;
      for (uint8_t i = 0; i < filled; i++) {
        lo = min(lo, win[i]); hi = max(hi, win[i]);
      }
      bool settled = filled == 50 && (hi - lo) < SETTLED_MM && ms - tStartMs > 2000;
      if (settled || ms - tStartMs > MAX_MS) {
        Serial.println("END");
        state = DONE;
      }
      break;
    }

    case DONE:
      digitalWrite(LED, LOW);
      if (digitalRead(BTN) == LOW) { delay(30); state = ARMED; }
      break;
  }
}

Analysis

Capture and fit

Two short scripts. The first saves one trial to a CSV. The second fits x(t) = A·e−γt·cos(ωt + φ) and reports the period, the damping constant and the damping coefficient b = 2mγ, which is the same b as in the lab manual formula 2m√(ω₀² − ω²).

capture.py
import sys, serial                      # pip install pyserial

port, out = sys.argv[1], sys.argv[2]    # e.g. COM3 water_1.csv
ser = serial.Serial(port, 115200, timeout=2)
rows = []
print("Ready. Press the button, then pull and release the mass.")
while True:
    line = ser.readline().decode(errors="ignore").strip()
    if line == "t_ms,d_mm":
        rows = []                       # a new trial has started
    elif line == "END":
        break
    elif line and line[0].isdigit():
        t, d = line.split(",")
        rows.append((float(t), int(d)))

with open(out, "w") as f:
    f.write("t_ms,d_mm\n")
    f.writelines(f"{t},{d}\n" for t, d in rows)
print(f"Saved {len(rows)} samples to {out}")
fit.py
import sys
import numpy as np, pandas as pd
from scipy.optimize import curve_fit
from scipy.signal import find_peaks

df = pd.read_csv(sys.argv[1])
mass = float(sys.argv[2])                    # kg, e.g. 0.200
t = df.t_ms.to_numpy() / 1000
x = df.d_mm.to_numpy(float)
x -= np.median(x[-25:])                      # rest position from the settled tail

i0 = np.argmax(x[: int(3 / np.median(np.diff(t)))])   # the release point
t, x = t[i0:] - t[i0], x[i0:]

def model(t, A, g, w, phi):
    return A * np.exp(-g * t) * np.cos(w * t + phi)

peaks, _ = find_peaks(x, prominence=3)       # needs 2+ peaks, so not for heavy damping
T0 = np.mean(np.diff(t[peaks])) if len(peaks) > 1 else 1.0
(A, g, w, phi), cov = curve_fit(model, t, x, p0=[x[0], 0.5, 2 * np.pi / T0, 0.0])
sg, sw = np.sqrt(np.diag(cov))[[1, 2]]

T = 2 * np.pi / w
print(f"period T      = {T:.4f} s  (+/- {T * sw / w:.4f})")
print(f"damping gamma = {g:.4f} 1/s (+/- {sg:.4f})")
print(f"damping b     = {2 * mass * g:.4f} kg/s")
print(f"log decrement = {g * T:.3f}")

Before you quote numbers

  • Move the flag to four known distances with a ruler and compare the readings. Put that small table in the report as the sensor calibration.
  • Run at least five trials per liquid and report the mean and standard deviation of T and γ.
  • Time the same setup once with a stopwatch and compare the spread. This is the improvement the logger buys.
  • If shampoo-water dies out in fewer than four swings, use a lighter mass or a softer spring so the fit has more peaks.
  • The first rise in each trace is your hand pulling the mass. The script starts the fit at the release point, which is the highest displacement in the first three seconds.
Sensor noise, drag values and the stopwatch error in the simulation are assumptions made for illustration. Measure the real rig before relying on any number here. Sketch written for the Pololu VL53L1X Arduino library. Check the pin labels on your own breakout before powering it.
